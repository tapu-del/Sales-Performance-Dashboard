# Sales Performance Dashboard

## Project Overview
Analyzed 2,824 sales records to understand sales performance across product lines, deal sizes, countries, and years.

## Tools Used
- Power BI
- Excel

## What I Did
- Analyzed total sales, quantity, orders, and average price
- Created KPI cards for key metrics
- Built bar chart for sales by product line
- Created pie chart for deal size distribution
- Added area chart for yearly sales trend
- Built bar chart for sales by country
- Added slicer for Product Line filter

## Key Insights
- Total Sales: $10.03M
- Total Quantity: 99K
- Total Orders: 2,823
- Classic Cars is the top product line ($3.9M)
- Medium deal size = 60.60% of sales
- USA has highest sales ($3.6M)
- Sales peaked in 2004 ($4.7M)
